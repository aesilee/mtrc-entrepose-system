1. System Overview

ENTREPOSE is a web-based patient monitoring information system built for MTRC. It digitizes the entire outpatient drug rehabilitation workflow — from the moment a patient is referred, through 7 months of therapy sessions, all the way to discharge and aftercare.

What Problem Does It Solve?

Before ENTREPOSE, MTRC used paper-based records — folders, logbooks, and handwritten forms. This caused:

  • Slow record retrieval
  • Risk of lost or damaged files
  • Manual counting for DOH reports
  • No real-time tracking of patient progress

Tech Stack

Layer Technology
Frontend React (Vite)
Backend Express.js (Node.js)
Database MySQL
Auth JWT (JSON Web Tokens)

Who Uses It?

Four types of staff use the system, each with different permissions (explained in Section 2).

Step 1: Referral

A patient arrives at MTRC through one of these sources:

  • Voluntary Walk-In — The person comes on their own
  • Court-Mandated — A judge orders them to attend (often through Plea Bargaining)
  • LGU-Referred — Local government refers them (CADAC/MADAC/BADAC)
  • Workplace-Referred — Their employer refers them
  • NGO-Referred — A non-government organization refers them

Step 2: Registration (IDADIN 5-Step Intake Workflow)

The Admitting Personnel enters the patient into the system using a 5-step workflow:

Step Name What's Collected
1 Patient Registration Full name, birthdate, gender, address, contact info, photo, emergency contact, living arrangement
2 Referral & Admission Info Referral source, admission type (new/readmission), nature of confinement (legal track), ASSIST risk level, DDE diagnosis, baseline drug test, prior hospitalizations
3 Drug Use History Substances used, age at first use, frequency, length of use, primary reason, drug source, daily expense
4 Clinical Triage Vital signs (BP, pulse, temp, weight), mental status exam, comorbidities (medical + psychiatric), socioeconomic classification
5 Finalize & Enroll Signed consents (4 forms), program orientation date, admission date, case manager assignment → Patient becomes ACTIVE
IDADIN = The name of the DOH-standard intake/registration form used in drug rehab facilities.

Step 3: Program Orientation (PO)

After enrollment, the patient attends an orientation session where they learn about:

  • The program rules and schedule
  • Their rights and responsibilities
  • The treatment plan process
  • The 43 core sessions they need to complete

Step 4: Active Treatment (7 Months)

This is the main treatment phase. The patient must complete 43 core sessions total:

Session Type Count Description
CBT Group Sessions 28 Group therapy using cognitive-behavioral techniques
Psycho-Education Sessions 12 Educational sessions about drugs, recovery, and life skills
CBT-E Evaluations 3 Formal evaluations (beginning, middle, end of treatment)
Total Core 43 Required for completion

Additional sessions (not counted toward the 43, but still important):

  • SHGM (Self-Help Group Meetings)
  • Individual Counseling
  • Conjoint/Family Sessions
  • Life Skills Training
  • Home Visits
  • ASI Interviews

During each session:

1. Attendance is recorded (present, absent, late, excused)

2. A Multi-3 Rapid Drug Test is administered to every present patient

3. Relapse risk is assessed (SAFE, AT RISK, or USED)

4. Progress notes (SOAP format) are written

Step 5: Pre-Discharge Conference (PDC)

When a patient completes all 43 core sessions and meets all requirements, a Pre-Discharge Conference is held. This is the final review before graduation.

Requirements to be eligible for completion:

  • ✔ At least 7 months since admission
  • ✔ 43 core sessions attended (28 CBT + 12 PE + 3 CBT-E)
  • ✔ No positive drug tests on record
  • ✔ PDC milestone date recorded
  • ✔ Patient must be "active" or "completed" status

Step 6: Discharge

The patient is formally discharged with one of these outcomes:

Discharge Type Meaning
Completer (Graduated) Successfully finished the 7-month program
Dropped Left the program before completing (AWOL, non-compliance)
Transferred Moved to another facility

Step 7: Aftercare (SIBOL Program)

Completers who graduate can transition to the 9-Month Community Aftercare Program called SIBOL. Their program phase changes to "Aftercare."

5. Session Types & Therapy Framework

The CBT Framework

CBT = Cognitive Behavioral Therapy — the main therapeutic approach used at MTRC.

CBT is based on the idea that our thoughts, feelings, and behaviors are all connected. By changing negative thought patterns, patients can change their behavior (substance use).

Session Types in ENTREPOSE

Code Full Name Description Count Toward 43?
CBT_GROUP CBT Group Session Group therapy (5-12 patients) using CBT techniques ✔ Yes (28 sessions)
PSYCHO_EDUCATION Psycho-Education Educational sessions about addiction, recovery, health ✔ Yes (12 sessions)
INDIVIDUAL_COUNSELING Individual Counseling One-on-one therapy session ✖ No (supplementary)
CONJOINT_FAMILY Conjoint/Family Session Session with patient and their family ✖ No (supplementary)
SHGM Self-Help Group Meeting Peer-led support group (like AA/NA style) ✖ No (supplementary)
LIFE_SKILLS Life Skills Training Practical skills for daily living ✖ No (supplementary)
ASI_INTERVIEW ASI Interview Addiction Severity Index assessment ✖ No (assessment)
HOME_VISIT Home Visit Case manager visits patient's home ✖ No (supplementary)
PROGRAM_ORIENTATION Program Orientation Initial orientation for new patients ✖ No (one-time)

CBT-E Evaluations

CBT-E = CBT Evaluation — formal assessments done at three points during treatment:

Evaluation When Purpose
CBTE-1 Beginning of treatment Baseline assessment of recovery domains, coping skills, life goals
CBTE-2 Mid-treatment Follow-up assessment to measure progress
CBTE-3 End of treatment Final evaluation before discharge

Each CBT-E evaluation records:

  • Recovery domain scores
  • Coping skills assessment
  • Life goals text
  • Overall score
  • Clinical judgment (ON_TRACK, NEEDS_ATTENTION, AT_RISK)

SHGM Special Rules

  • SHGM = Self-Help Group Meeting
  • These are peer-led meetings, not facilitated by professionals
  • A patient is elected as Chairperson for each meeting
  • 5-session term limit: No patient can chair more than 5 SHGM sessions (ENTREPOSE Vol. 1 Sec 5.5.3)
  • The system enforces this rule automatically

6. Drug Testing Protocol

Multi-3 Rapid Drug Test

MTRC uses the Multi-3 Rapid Urine Drug Test after every session. This test screens for 3 substances:

Substance Code Color Badge What It Detects
THC THC ● Green Marijuana/Cannabis
METH METH ● Blue Methamphetamine (Shabu)
ECS ECS ● Purple Ecstasy (MDMA)

How Drug Testing Works in the System

1. During attendance recording (Step 3), each present patient's drug test result is marked as POSITIVE or NEGATIVE

2. If POSITIVE, checkboxes appear for which substance(s) were detected (THC, METH, ECS)

3. A patient can be positive for multiple substances at once ("poly-positive")

4. Results are logged in the drug_test_logs table automatically

5. Positive results trigger automatic notifications and follow-up scheduling

Baseline Drug Test

At referral (Step 2 of registration), a baseline drug test is recorded:

  • Date of test
  • Reference number
  • Which substances were detected (METH, THC, Other)
  • Finding (Positive/Negative)

Drug Test Types in the System

Type When
Post-Session Screening Automatically logged after every session attendance
Random Screening Logged manually through Case Management
Baseline Recorded during referral registration

Milestones are important dates in a patient's treatment journey. The case manager records these dates as they happen.

Milestone Code When It Happens

8. Certificates

The system generates two types of official certificates:

Enrollment Certificate (ENROLLMENT)

  • Who can issue: Admitting Personnel, ICT Admin
  • When: After a patient completes the intake workflow and is enrolled
  • Requirement: Patient must have an admission date
  • Control Number Format: CERT-ENR-[YY]-[XXXXX]

Completion Certificate (COMPLETION)

  • Who can issue: Case Manager, HIM Staff, ICT Admin
  • When: After a patient completes the full 7-month program
  • Requirements (all must be met):

- ✔ Patient status is "active" or "completed"

- ✔ At least 7 months since admission

- ✔ 43 core sessions attended

- ✔ Zero positive drug tests

- ✔ PDC milestone date recorded

  • Control Number Format: CERT-CMP-[YY]-[XXXXX]

Court Progress Reports

Not certificates, but formal documents generated for the court:

Report Type Code When
Initial INIT Around 30 days after enrollment
Midterm MID Around mid-treatment
Final FNL At program completion

Each includes: attendance summary, drug test summary, relapse risk stats, clinical narrative, and case manager recommendation.

2 consecutive absences Assigned case manager "Clinical Flag: [name] has 2 consecutive absences — needs follow-up"

43 sessions completed Assigned case manager "Milestone Alert: [name] has completed 43 core sessions — ready for PDC"
Relapse risk: AT RISK or USED Assigned case manager "Relapse Risk Alert: [name] rated [risk level] — immediate follow-up required"
Patient discharged ICT Admin + HIM Staff + Admitting "Patient discharged: [name] — [type]"
Attendance recorded ICT Admins Summary: "[session] — X present, Y absent, Z positive"
Initial court report due Case manager (via attention flags) "[name] — Initial Court Report Due (>30d Enrolled)"

Auto-Scheduled Follow-Ups

The system automatically creates follow-up tasks when:

  • A patient's relapse risk is AT_RISK or USED
  • A patient tests positive on a drug test
